# Sécurité

Pour signaler une faille, **n'ouvre pas d'issue publique**. Utilise « Report a vulnerability » dans l'onglet
Security du dépôt (signalement privé à [@samirmedani](https://github.com/samirmedani)). Décris le problème, comment le
reproduire et son impact ; une réponse est donnée dès que possible.

Points sensibles de Wispad : clés API (fichier de l'app ou coffre de secrets), audio et transcriptions (jamais
journalisés), accès d'accessibilité et collage dans les autres apps.

*To report a vulnerability, use "Report a vulnerability" in the Security tab. Please do not open a public issue.*
